# Project Analytics Bot

Единый Telegram-бот статистики по проектам. Он читает отправки и ответы из
Dialog Hub, а TG-заявки записывает в него заявки на вступление и одобрения.

## Отчёты

- ежедневно в 00:01 МСК — за предыдущий день;
- по понедельникам в 00:01 МСК — недельный отчёт за завершённую неделю;
- первого числа в 00:01 МСК — месячный отчёт за завершённый месяц;
- кнопки: «Вчера», «Эта неделя» и «За всё время».

Раздел «Скрипты» доступен отдельной кнопкой для «Госзакупок» и «Трейдинга».
Он показывает результаты за всё время: рабочие тексты с достаточной выборкой,
тексты, которым нужна доработка, и ещё не набравшие выборку гипотезы.

Первый пользователь, который отправит `/start` боту, автоматически назначается
администратором и чатом для автоматических отчётов. В группе используйте
`/set_report_chat` от имени администратора.

## Интеграция TG-заявок

`approvedApplications.py` отправляет два идемпотентных события в локальный
endpoint: `join_request` (заявка поступила) и `join_approved` (одобрена).
Идентификатор события построен по проекту, пользователю и времени, поэтому
повторная доставка не удваивает статистику.

## Связи и границы проекта

Бот учитывает события переписки из `tg-dialog-hub` и события заявок из `tg-auto-approve-bot`, затем формирует отчёты по проектам. Получение события и успешная доставка отчёта — разные этапы.
